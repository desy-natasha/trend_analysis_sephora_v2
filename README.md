# Aspect-Level Sentiment and Trend Analysis of Beauty Consumer Reviews from Sephora

## Overview
This repository contains sentiment and trend analysis of beauty reviews from Sephora. The framework integrates topic modelling, taxonomy design, and an aspect-level sentiment analysis model to identify pattern changes over time in customer feedback across product types, brands, and attributes. The process includes data preparation, exploratory data analysis (EDA), sentiment analysis, and aspect significance measurement to derive meaningful insights from beauty consumer reviews.

**Note**: *This work is based on my master's thesis and is currently being prepared for submission to an international conference. The abstract is available in this repository.*

## Repository Structure
- **data/**: Input datasets containing Sephora product and review data, and manually labelled set.
- **log/**: Log files and output records generated during data scraping.
- **src/**: Source scripts and helper modules used in scraping, semantic chunking, data sampling, and ABSA model architecture.
- **trend_analysis_sephora.ipynb**: The main notebook implementing the sentiment and trend analysis.
